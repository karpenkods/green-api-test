## GREEN-API

### Приложение для обмена текстовыми сообщениями через мессенджер Telegram


### Проект доступен ао адресу:
https://green-api-test-nu.vercel.app/

#### Для доступа к чату необходимо ввести свой idInstance и 
#### apiTokenInstance, полученнные на сервисе GREEN-API, после создания Инстанса


### Запуск приложения в dev-режиме:

1. Склонировть проект на локальный компьютер.

2. Запустить команду npm install

3. Запустить команду npm dev

4. Проект будет доступен по адресу: http://localhost:3000/

#### Для запуска тестов выполните команду npm run test


### Для сборки приложения в prod-режиме:

1. Склонировть проект на локальный компьютер.

2. Запустить команду npm install

3. Запустить команду npm run build

4. Сборка находится в папке build
